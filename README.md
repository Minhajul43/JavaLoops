# JavaLoops

A beginner-friendly Java repository containing loop examples and practice programs.

This repository is created to learn Java loop concepts while also practicing professional Git and GitHub workflows.

---

## 📚 Topics Covered

- for Loop
- while Loop
- do-while Loop
- Nested Loops
- User Input
- Pattern Printing
- Basic Java Programs
